# Medical MCQ Expert Review Prototype

Large language models can help medical educators prepare multiple-choice questions, while medical experts remain responsible for reviewing their clinical content, difficulty, case clues, and distractors.

This research prototype explores how Text and knowledge graph explanations can support this review process. Medical experts can examine generated questions, check the presented clinical reasoning, and refine the questions through different review actions.

## Open the Prototype

Use the following page to enter the prototype:

[**Open counterbalance-2.html**](https://laozishan.github.io/MCQUSERSTUDY/counterbalance-2.html)

## Main Features

- Review clinical vignette-based MCQs
- Examine Text, knowledge graph, or combined explanations
- Highlight linked content across the vignette and explanations
- View detailed explanations by hovering over knowledge graph nodes
- Accept, revise, regenerate, or reject questions
- Save reviewed questions in the question bank

The prototype was developed for a Wizard-of-Oz user study on expert review of AI-generated medical MCQs.
